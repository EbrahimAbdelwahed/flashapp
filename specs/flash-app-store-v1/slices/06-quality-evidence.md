# Slice 06 — Quality, privacy and release evidence

## Contract unlocked

Every locally provable App Store gate has repeatable evidence and every external gate is
visibly distinguished from PASS.

## API seam and ownership

CI scripts own automated matrices; `docs/testing/app-store-v1-gates.md` owns tri-state
release evidence. App Privacy, required-reason, license and entitlement inventories derive
from the exact release product rather than assumptions.

## Runnable artifact

One release-readiness command/document index shows iOS 17/current, iPhone/iPad, EN/IT,
appearance, accessibility, import/security, persistence/relaunch, backup and offline cells.

## Verification

- Default CI loses no existing coverage and adds data/relaunch/backup/localization gates.
- Archive privacy report/Required Reason API and final entitlement checks are prepared but
  remain `HUMAN_REQUIRED` until an exact signed archive exists.
- Dependency and asset license inventory covers FSRS, Markdown/cmark, zstd, icons, demo and
  screenshots.
- `.apkg` audit reuses existing caps/tests and adds only evidence-backed gaps.
- No secret, placeholder legal claim, unsupported accessibility label or false PASS remains.

## Feedback that changes this slice

New archive warnings or App Store requirements reslice the affected audit; they do not
silently weaken the gate.
